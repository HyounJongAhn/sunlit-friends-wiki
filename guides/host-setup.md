# 운영자용 설치와 서버 켜기

GitHub에서는 `MinecraftFriends-Server.zip`을 받아요. 직접 전달받은 `마인크래프트 서버 준비.zip`도 같은 압축 파일입니다.

[← 공략 목차](index.md) · [처음 화면](../README.md) · [다운로드](https://github.com/HyounJongAhn/sunlit-friends/releases/latest)

**서버는 내가 켜둔 동안만 친구들이 들어올 수 있어요.** 일반·포켓몬 서버는 따로 보관하며, 관리기에서는 한 번에 한 시즌만 켭니다. 본인도 플레이하려면 [친구용 설치](friend-install.md)를 따로 진행해요.

## 1. 새 PC에서 처음 준비하기

1. **마인크래프트 서버 준비.zip**을 받아 새 폴더에 전부 풀어요. ZIP 안에서 바로 실행하지 마세요.
2. **처음 서버 준비.cmd**를 두 번 눌러요. 통합 준비 도구는 다른 모드팩까지 함께 받아 시간과 공간이 더 필요할 수 있어요.
3. 선택한 원본 서버와 Java, 접속 도구를 받을 때까지 기다려요. Python이나 Java를 따로 설치할 필요는 없어요.
4. 준비가 끝나면 관리기가 열려요. 이후에는 같은 폴더의 **서버 관리기.cmd**를 사용하면 됩니다.

기존 서버 폴더를 찾으면 준비 도구는 설치 상태를 확인하고 보관해요. 이 도구를 다시 실행하는 것만으로 이미 있는 서버의 패치가 최신으로 바뀌지는 않아요. 기존 서버 업데이트는 해당 릴리스의 안내를 따르고, 먼저 백업해주세요.

## 2. 내 계정으로 서버 시작하기

1. 관리기에서 **일반 시즌** 또는 **포켓몬 시즌**을 골라요. 친구들의 설치기와 같은 시즌으로 맞춰요. 처음에는 서버 메모리 **8GB**로 시작해요.
2. **서버 켜기**를 눌러요. 이용 약관 확인 창이 나오면 내용을 읽고 본인이 동의해요.
3. 상태가 **서버가 열렸어요**로 바뀔 때까지 기다려요. 첫 실행은 더 오래 걸릴 수 있어요.
4. 닉네임 칸에 본인의 **Minecraft Java 닉네임**을 넣고 **운영자로 지정**을 눌러요.
5. 실행 기록에서 접속 허용과 운영자 지정 결과를 확인해요.
6. 본인 게임 설치기의 주소 칸에는 관리기의 **내 PC에서 접속**에 표시된 주소를 복사해 넣어요.

새 배포본에는 다른 사람의 계정이나 이용 약관 동의가 미리 들어 있지 않아요. **운영자로 지정**은 접속 허용과 운영 권한을 함께 요청합니다. 기존 운영자를 지우는 버튼은 아니에요. 다른 시즌도 처음 열 때 본인 계정을 등록해주세요.

## 3. 바깥의 친구가 들어오게 하기

1. 관리기에서 **친구 접속 설정 → 연결 프로그램 열기**를 눌러요.
2. playit 안내에 따라 본인 계정으로 로그인하고 **Minecraft Java 연결**을 만들어요.
3. 연결 대상은 관리기의 안내에 나온 서버 PC 내부 주소와 포트를 사용해요. 기본 포트는 **25565**입니다.
4. 발급받은 공개 주소를 관리기에 저장해요.
5. **서버를 켤 때 친구 접속도 함께 연결**을 선택하면 다음부터 함께 켤 수 있어요.
6. 친구에게 설치 EXE와 그 공개 주소를 전달해요. 친구 PC에는 playit을 설치할 필요가 없어요.

관리기의 **내 PC에서 접속**은 서버 PC에서 본인이 들어갈 때 쓰는 값이에요. 친구에게는 playit에서 받은 공개 주소를 **친구에게 줄 주소**에 저장해서 보내주세요. 공유기 설정을 직접 바꾸는 다른 연결 방법은 이 기본 안내의 범위에 포함하지 않습니다.

## 4. 친구 접속 허용하기

서버가 열린 상태에서 친구의 Java 닉네임을 넣고 **친구 추가**를 눌러요. 허용 목록은 시즌별로 따로 관리합니다. 여러 시즌을 한다면 각 시즌에서 따로 추가해요.

일반 친구는 **친구 추가**만 하면 돼요. **운영자로 지정**은 게임 설정과 월드를 바꿀 권한까지 주므로 함께 운영할 사람에게 사용하세요.

## 5. 기본 마을과 개인 집터 준비하기 — 선릿밸리 전용

최신 관리기의 **마을 준비 → 마을 파일 적용 + 백업**을 서버가 꺼진 상태에서 눌러요. 그다음 접속해서 빈 부지를 고르고 `/sunlit town`을 열면 미리 확인과 설치를 진행할 수 있어요. 기존 월드를 초기화하지 않습니다.

준비된 마을에는 여섯 빈 집터와 공용 광장·벚꽃길·수로가 있고, 친구들이 재료를 모아 작업장과 시장을 늘릴 수 있어요. **부지 선택, 주민 상점 설치, 집터 권한과 공사 복구 방법은 [마을 공략](town.md)을 먼저 읽어주세요.**

## 도움말용 안내 주민 놓기 — 선릿밸리 전용

본인이 게임에 접속해 평평하고 주변이 넓은 곳에 서요. 관리기에 본인 닉네임을 넣고 **이 친구 옆에 안내인 놓기**를 눌러요.

안내인·어부·목수·상점 주인 네 명이 생깁니다. 우클릭하면 짧은 도움말을 줘요. 독자적인 거래 상점이나 이야기 퀘스트를 진행하는 주민은 아니에요. 같은 배치 버튼을 다시 눌러도 중복으로 만들지 않도록 되어 있어요.

## 6. 매번 켜고 끄는 순서

**시작:** 관리기 열기 → 시즌 선택 → 서버 켜기 → 준비 완료 확인 → 친구에게 접속 알리기.

**종료:** 친구들에게 종료 알리기 → **저장하고 끄기** → 저장·종료·백업이 끝난 상태 확인 → PC 종료.

관리기 창만 닫는 선택은 서버 종료와 달라요. 종료가 목적이면 **저장하고 끄기**를 사용하세요. 백업 실패 표시가 나오면 완료한 것으로 넘기지 말고 디스크 공간과 실행 기록을 확인해요.

## 백업하고 되돌리기

수동 **지금 백업**과 **백업 복원**은 서버를 끈 상태에서 사용해요. 복원할 때는 같은 시즌의 백업을 고릅니다. 관리기는 현재 상태를 먼저 백업한 다음 선택한 시점으로 되돌려요. 그 시점 이후의 플레이 내용은 되돌아가므로 친구들에게 먼저 알려주세요.

백업에는 마을과 설정이 들어가요. 다시 받을 수 있는 모드와 Java 전체를 넣는 방식은 아니에요. 다른 PC로 옮길 때는 새 PC에서 서버를 준비한 뒤 백업 파일을 옮겨 같은 시즌에 복원해요. playit 로그인은 새 PC에서 다시 진행합니다.

## 처음 쓸 성능 설정

| 항목 | 32GB 서버 PC의 시작값 |
| --- | --- |
| 서버 메모리 | 8GB |
| 내 게임 메모리 | 기본 8GB |
| 서버 시야 / 처리 거리 | 8 / 6 |
| 동시에 실행할 시즌 | 1개 |
| 쉐이더 | 기본 끔 |

서버와 게임뿐 아니라 Windows와 다른 앱도 메모리를 사용해요. 메모리를 무조건 많이 주기보다 첫 플레이에서 상태를 확인하세요. 이 설정으로 **6인 렉 없음이 검증된 것은 아닙니다.** 자세한 범위는 [검증 안내](verification.md)에 있어요.

다른 모드팩인 Craft to Exile 2의 서버는 [우리의 원정대 서버 안내](https://hyounjongahn.github.io/exile-friends-wiki/#guide/rpg-host)를 따라가요.
