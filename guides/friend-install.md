# 친구용 설치

GitHub에서는 `MinecraftFriends-Setup.exe`를 받아요. 직접 전달받은 `마인크래프트 친구 설치.exe`도 같은 설치기입니다.

[← 공략 목차](index.md) · [처음 화면](../README.md) · [다운로드](https://github.com/HyounJongAhn/sunlit-friends/releases/latest)

**Windows PC, 기본 Minecraft Launcher, Minecraft Java를 가진 Microsoft 계정, 서버 주인이 보내준 접속 주소**를 준비해요. 서버 주인에게 본인의 **Java 닉네임**도 알려주세요. Xbox 표시 이름이나 Microsoft 이메일과 다를 수 있어요.

0.1.8부터는 **Microsoft의 기본 Minecraft Launcher**로 실행해요. 우리 설치기는 모드와 시즌 설정을 준비하고, 계정 로그인과 게임 실행은 기본 런처가 맡습니다. Prism을 새로 설치할 필요는 없어요.

## 처음 설치할 때

1. 최신 릴리스에서 **MinecraftFriends-Setup.exe**를 받아 열어요. 서버 주인이 보내준 같은 설치기를 열어도 됩니다.
2. 친구들과 정한 **선릿밸리 / 일반** 또는 **포켓몬 / 탐험** 카드를 골라요.
3. 화면 설정을 골라요. 32GB PC에서는 우선 **기본 · 메모리 8GB**, 느리면 **가볍게 · 메모리 6GB**로 시작해요.
4. 받은 서버 주소를 붙여 넣고 **설치 / 업데이트**를 눌러요.
5. **런처 바로 열기**를 눌러 기본 런처에서 본인의 Microsoft 계정으로 로그인해요. 처음 쓰는 런처라면 **Java Edition** 화면을 한 번 연 뒤 런처를 완전히 닫아요.
6. 설치기에서 **시즌 등록 / 열기**를 눌러요. 필요한 Forge를 준비하고, 선택한 시즌을 기본 런처에 등록합니다.
7. 기본 런처의 **Java Edition**에서 **선릿밸리 · 일반 시즌** 또는 **선릿밸리 · 포켓몬 시즌**을 고른 뒤 **플레이**를 눌러요.
8. 게임의 **멀티플레이**에서 준비된 서버를 선택해요. 서버 주인이 같은 시즌을 열어둬야 들어갈 수 있어요.

처음에는 원본 모드팩, Java, Forge와 게임 파일을 받아서 시간이 걸려요. 다운로드하는 동안 창을 사용할 수 있고, 중단했다면 **설치 / 업데이트**를 다시 누르면 돼요. 기본 런처가 없다면 [Minecraft 공식 다운로드](https://www.minecraft.net/download)에서 먼저 설치해주세요.

Microsoft 로그인은 기본 Minecraft Launcher에서 본인이 진행합니다. 친구용 설치기에는 비밀번호를 넣는 칸이 없어요. 기본 런처의 **최신 릴리스**를 선택하면 다른 버전으로 실행될 수 있으니, 설치한 시즌의 항목을 골라주세요.

### 런처가 있는데 못 찾는다고 나와요

설치기의 **설치 설정 + → 런처 파일 선택**을 누르고, 설치된 런처의 `Minecraft.exe` 또는 `MinecraftLauncher.exe`를 골라요. Xbox 앱으로 설치했다면 `C:\XboxGames\Minecraft Launcher\Content\Minecraft.exe`처럼 `Content` 폴더 안에 있을 수 있어요. 다른 드라이브에 설치했다면 해당 드라이브에서 찾아주세요.

선택한 위치는 다음에도 기억해요. 선택 후 **런처 바로 열기**로 열거나, 로그인과 첫 실행을 이미 마쳤다면 런처를 닫고 **시즌 등록 / 열기**를 눌러요. **설치 위치**는 우리 모드팩을 보관하는 폴더이므로 런처 파일을 지정할 때 바꾸지 않아도 돼요.

## 다음 날 다시 플레이할 때

시즌 설치와 등록을 마쳤다면 **런처 바로 열기 → 기본 런처에서 해당 시즌 선택 → 플레이**만 하면 돼요. 매번 설치나 시즌 등록을 다시 할 필요는 없어요. **런처 바로 열기**는 모드 설치 전에도 사용할 수 있고, 새 파일을 받거나 프로필을 다시 등록하지 않습니다. 처음 로그인하거나 계정을 바꿀 때도 같은 버튼을 사용해요.

## 여러 시즌을 함께 설치하고 싶어요

시즌을 바꾸고 **설치 / 업데이트 → 시즌 등록 / 열기**를 진행해요. 두 시즌은 서로 다른 게임 폴더와 기본 런처 프로필로 보관합니다. 기본 런처에서도 오늘 할 시즌을 골라요.

| 선택 | 달라지는 것 | 함께 유지되는 것 |
| --- | --- | --- |
| 일반 ↔ 포켓몬 | 사용하는 모드팩과 접속할 서버 월드 | 이미 설치한 다른 시즌 |
| 기본 ↔ 가볍게 | 다음 실행의 메모리와 화면 설정 | 게임 콘텐츠와 친구들과의 호환 |

포켓몬 시즌은 일반 시즌에 모드 몇 개를 직접 끼워 넣는 방식이 아니에요. 설치기에 있는 시즌 선택을 사용해주세요.

## 업데이트하거나 파일을 고칠 때

1. 게임과 기본 런처를 완전히 종료해요.
2. 최신 설치 EXE를 열고 기존과 같은 설치 폴더와 시즌을 골라요.
3. **파일 검사**로 빠지거나 달라진 파일을 확인해요.
4. **설치 / 업데이트**를 눌러 복구하고, **시즌 등록 / 열기**로 실행 설정을 맞춰요.

개인 월드, 스크린샷, 지도 자료와 키 설정, 기존 서버 목록은 보존하도록 되어 있어요. 서버 주소가 바뀌었다면 게임의 **멀티플레이 → 해당 서버 → 수정**에서 바꿔주세요. 설치기의 주소 입력란은 서버 목록을 처음 만들 때 사용해요. 직접 바꾼 모드와 팩 설정은 배포본 구성으로 복구될 수 있으니, 수정 작업은 별도 사본에서 해주세요.

0.1.7까지 Prism으로 설치했다면 **기존과 같은 설치 위치**를 선택해요. 시즌의 게임 폴더를 그대로 사용하므로 다시 새 폴더로 옮길 필요는 없어요. 기본 런처에는 계정을 처음 한 번 로그인해야 합니다.

## 설치 위치와 다음 단계

기본 폴더는 `%LocalAppData%\SunlitFriends`예요. **설치 설정 +**를 열면 **설치 위치 변경**, **설치 폴더 열기** 버튼이 나와요. 자주 바꾸기보다 한 폴더를 계속 쓰는 편이 편합니다. 예전 설치를 계속 사용할 수 있도록 폴더 이름은 그대로 유지해요.

[처음 30분](first-30-minutes.md)을 읽으면 돼요. 실행이 안 되면 [문제 해결](troubleshooting.md)에서 증상을 찾아보세요.

다른 모드팩인 Craft to Exile 2는 [우리의 원정대 설치 안내](https://hyounjongahn.github.io/exile-friends-wiki/#guide/rpg-install)에서 따로 안내해요.
